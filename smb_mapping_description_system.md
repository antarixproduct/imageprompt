# SMB Prompt Description Mapping System

# Purpose

This document contains predefined description mappings for your SaaS platform.

The system will:
- take structured user selections
- map them to predefined description blocks
- dynamically assemble final design descriptions

---

# Example System Logic

## User Selection

```text
Platform = Instagram Post
```

## Internal Mapping

```text
Instagram-focused square social media post with 1:1 ratio, mobile-first composition, bold readable typography and attention-grabbing layout.
```
